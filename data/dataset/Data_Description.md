# 数据集说明
四个真实世界的交通流量数据集，具体数据集属性如下表所示：

| 属性         | PEMS03   | PEMS04   | PEMS08   | Seattle  |
| ------------ | -------- | -------- | -------- | -------- |
| 时间范围     | 3个月    | 2个月    | 2个月    | 1年      |
| 采样间隔     | 5分钟    | 5分钟    | 5分钟    | 1小时    |
| 节点数量     | 358      | 307      | 170      | 323      |
| 流量均值     | 179      | 207      | 229      | 879      |
| 流量标准差   | 143      | 156      | 145      | 525      |

上述数据集描述如下：

- **PEMS03、PEMS04、PEMS08**：这三个数据集均源自加州高速公路交通监测系统（PEMS），以5分钟为采样间隔，时间跨度分别为3个月、2个月和2个月。PEMS03仅包含流量（flow）特征，而PEMS04和PEMS08包含流量（flow）、速度（speed）、和占有率（occupancy）。
- **Seattle**：西雅图区域交通数据，时间跨度为1年，时间间隔被处理为1小时，提供流量、速度和占有率数据。

以上数据集广泛用于交通预测任务，包括节点级交通流量、速度和占有率的时空建模。
